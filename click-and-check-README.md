# Click & Check

A modern luxury perfume and gift website designed and developed for **Click & Check**.

The project combines an elegant black-and-gold visual identity with responsive layouts, smooth interactions, animated UI elements, and a custom 3D shopping bag experience.

## Live Demo

https://mustafa-maqadmeh.github.io/click-and-check/

## Features

- Luxury black-and-gold visual design
- Fully responsive layout for desktop, tablet, and mobile
- Interactive hero section
- Custom 3D shopping bag built with Three.js
- Smooth hover effects and animated buttons
- Perfume collection showcase
- Interactive scent preference finder
- Instagram, WhatsApp, and Facebook contact options
- Smooth scrolling and modern UI transitions
- Mobile-friendly product and collection layouts

## Design Direction

The website was designed around a premium perfume-store aesthetic using:

- Deep black backgrounds
- Warm gold accents
- Elegant typography
- Subtle glow and shimmer effects
- Smooth modern animations
- Luxury product presentation

## 3D Experience

The hero section includes a custom interactive 3D shopping bag created with **Three.js**.
The model includes subtle floating movement, lighting, depth, and pointer interaction to make the landing experience more immersive.

## Responsive Design

The interface was optimized for multiple screen sizes, including:

- Desktop
- Tablet
- 430px mobile
- 390px mobile
- 360px mobile
