# Click and Check — كيس 3D للموقع

مجسم WebGL حقيقي بأسطح أمامية وخلفية وجوانب مطوية، مقابض ذهبية مجدولة وورق هدايا. يطفو ويتمايل تلقائياً ويستجيب لحركة المؤشر بميلان خفيف. لا صوت أو رذاذ أو أزرار أو نقرات.

هذا مجسم هندسي مستوحى من صورة التصميم، وليس تحويل الصورة فوتوغرافياً إلى مجسم مطابق. الصورة الأصلية تظهر مؤقتاً أثناء التحميل أو كبديل إذا تعذر WebGL.

## التجربة
افتح demo.html باستخدام Live Server في VS Code.

## التركيب داخل الموقع الحالي
1. انسخ مجلد bag-3d كاملاً داخل click-and-check، بجانب index.html.
2. داخل head، بعد رابط styles.css، أضف:

<link rel="stylesheet" href="bag-3d/bag.css">

3. لاستبدال الشعار الدائري في الواجهة، ابحث عن:

<div class="brand-stage reveal">

واستبدل هذا العنصر كاملاً (الصورة والعبارة ووسم الإغلاق) بهذا السطر:

<div class="brand-stage reveal cc-bag" data-cc-bag></div>

احتفظ بكلاس brand-stage كما هو: هذا يجعل مستمعات script.js القديمة آمنة ويمنع خطأ العنصر غير الموجود. ملف bag.css يلغي حلقات الشعار القديمة داخل هذا العنصر فقط.

بدلاً من استبدال الشعار، يمكن إضافته في مكان مستقل داخل main:

<section><div class="cc-bag" data-cc-bag></div></section>

4. قبل إغلاق body أضف مرة واحدة:

<script type="module" src="bag-3d/bag.js"></script>

5. احفظ الملفات وشغّل index.html بواسطة Live Server. عند ظهور نسخة قديمة اضغط Ctrl+Shift+R.

## إزالة إضافة عبوة العطر السابقة (إن كنت ركّبتها)
احذف من index.html عنصر perfume3d القديم وأزراره، ورابط perfume-3d/perfume.css وسطر perfume-3d/perfume.js. لا تحذف script.js أو styles.css الأساسيين.

## الملفات
- bag.js: الإضاءة والكاميرا والحركة والشعار.
- model.js: الشكل الهندسي والخامات والمقابض.
- bag.css: حجم المجسم والتجاوب والتوافق مع الواجهة القديمة.
- brand-reference.png: مرجع الشعار. يتم أخذ رمز الفكرة الثالثة منه أثناء التشغيل.
- preview.png: صورة التصميم الأصلية، للتحميل والبديل الثابت.
- vendor: مكتبة Three.js المرفقة وترخيصها؛ لا يلزم npm أو CDN.

## التخصيص
- لإيقاف الحركة تماماً: اجعل ANIMATE = false في bag.js.
- الاسم: BRAND في bag.js.
- ارتفاع المجسم: .cc-bag في bag.css.
- قوة تتبع المؤشر: px*.23 وpy*.085 في bag.js.
- اللون الأسود والذهبي: مواد black وgold في model.js.

على الموبايل تعمل الحركة التلقائية دون الحاجة للمس. يتوقف الرسم عندما يغيب المجسم عن الشاشة أو تصبح الصفحة مخفية، ويحترم إعداد تقليل الحركة. يلزم Live Server أو استضافة HTTP/HTTPS لأن الكود يستخدم JavaScript modules.
